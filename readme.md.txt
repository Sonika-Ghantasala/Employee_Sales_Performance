📊 Employee Sales Performance Dashboard – Excel

📌 Project Overview

This project focuses on analyzing employee sales performance across multiple regions using Microsoft Excel. The dashboard provides an interactive view of individual sales performance, target achievement, and sales gaps over a five-day period.

The dataset contains employee details, regional information, daily sales figures, total sales, assigned targets, target achievement percentages, and remaining target percentages.

The main objective is to monitor employee performance, identify top and low performers, compare regional sales performance, and help businesses understand how effectively sales executives achieve their assigned targets.

🎯 Project Objectives

- Analyze individual sales executive performance.
- Identify the top 5 and bottom 5 sales performers.
- Evaluate employee target achievement percentages.
- Identify employees with the highest remaining sales gaps.
- Compare employee performance across different regions.
- Analyze daily sales performance over five days.
- Build an interactive dashboard for monitoring sales performance.

🛠️ Tools & Technologies

- Microsoft Excel – Data analysis and dashboard development.
- Excel Formulas – Calculating total sales, target achievement, and sales gaps.
- SUM Function – Calculating total sales from daily sales figures.
- Percentage Calculations – Measuring target achievement and remaining target percentages.
- Pivot Tables – Summarizing and ranking employee sales performance.
- Pivot Charts – Visualizing sales performance through different chart types.
- Slicers – Filtering dashboard data by region.
- Excel Form Controls – Dashboard selection controls.

🔄 Project Workflow

 1. Data Understanding
- Explored employee details, regional information, and daily sales records.
- Identified key performance indicators such as Total Sales, Target Hit %, and Away From Target %.
- Examined the relationship between daily sales and overall target achievement.

 2. Data Preparation
- Organized employee sales records for analysis.
- Verified daily sales figures and total sales calculations.
- Prepared target-related percentage calculations.
- Structured the dataset for Pivot Table analysis.

 3. Data Analysis
- Calculated total sales over five working days.
- Compared employee sales against a fixed target of 500.
- Evaluated target achievement percentages.
- Identified employees with the highest and lowest sales.
- Analyzed performance across multiple regions.

 4. Dashboard Development
- Created an interactive Excel dashboard with four dashboard selection controls.
- Developed a region-based filtering mechanism using slicers.
- Created Pivot Tables to identify top and bottom sales performers.
- Used bar, pie, and line charts to visualize sales performance.
- Designed separate performance views for total sales, target achievement, and remaining target percentages.


🔍 Key Business Insights

The dashboard helps businesses identify the following:

1. Top Performers: Identifies sales executives generating the highest total sales and contributing significantly to sales performance.

2. Low Performers: Highlights employees with the lowest sales figures who may require additional support or performance improvement.

3. Target Achievement: Identifies employees who are performing closer to their assigned sales targets based on target achievement percentages.

4. Sales Gap Analysis: Highlights employees with the highest percentage of targets remaining, helping managers identify performance gaps.

5. Regional Performance: Enables comparison of employee performance across different regions using interactive slicers.

6. Performance Comparison: Helps compare employee contributions based on total sales, target achievement, and remaining target percentages.

7. Performance Monitoring: Provides a consolidated view of employee performance to support sales monitoring and decision-making.
